اختصارات لوحة المفاتيح لدكتور إبراهيم (تعمل بمفردها أو مع Ctrl):
• مفتاح ذ / ` (أو Ctrl + ذ): نطق بيانات السؤال كاملة (الفقرة، المجال، دور الفريق، والنتيجة).
• مفتاح 1 (أو Ctrl + 1): نطق نص السؤال الحالي ونقل التركيز عليه.
• مفتاح 2 (أو Ctrl + 2): نطق الإجابة النموذجية فوراً ونقل التركيز لها.
• مفتاح 3 (أو Ctrl + 3 أو مسافة): تشغيل / إيقاف مؤقت / استئناف التايمر.
• مفتاح 4 (أو Ctrl + 4 أو حرف ا): طلب كشف الخيارات وإيقاف التايمر لأول مرة، وإعادة قراءتها.
• مفتاح 5 (أو Ctrl + 5): أجاب الفريق الأول / إجابة صحيحة واحتساب نقطة.
• مفتاح 6 (أو Ctrl + 6): أجاب الفريق الثاني / إجابة خاطئة وتحويل السؤال.
• مفتاح 7 (أو Ctrl + 7): في أسئلة السرعة (لم يجب أحد - سحب سؤال سرعة آخر).
