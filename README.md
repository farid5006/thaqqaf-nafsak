# ثقف نفسك (Thaqqaf Nafsak) - الإصدار الثالث v3.0.0
## إضافة رسمية لقارئ الشاشة NVDA لإدارة وتحكيم مسابقات المعلومات العامة

إضافة متكاملة ومستقلة تماماً (Zero-Dependency) مخصصة لقارئ الشاشة NVDA، صُممت لمساعدة مقدمي ومحكمي المسابقات الثقافية من المكفوفين (د. إبراهيم وفريد محمد) على إدارة وتحكيم مسابقات المعلومات العامة الإذاعية بدقة واحترافية عالية.

### جدول اختصارات لوحة المفاتيح والتحكم السريع لدكتور إبراهيم

صُممت واجهة التحكيم لتعمل بكفاءة مطلقة عبر لوحة المفاتيح دون الحاجة للمس الفأرة، مع استجابة فورية لقارئات الشاشة:

| الاختصار | الوظيفة الأساسية والسلوك أثناء المباراة |
| :--- | :--- |
| **Ctrl + ذ** (أو **Ctrl + \`**) | **نطق بيانات السؤال كاملة:** ينطق رقم السؤال الحالي للفريق، إجمالي أسئلته، رقم السؤال في الفقرة، رقمه العام في المباراة، واسم المجال والفريق النشط. وعند انتهاء المباراة ينطق ملخص النتيجة والفائز. |
| **Ctrl + 1** | **نطق السؤال والتركيز عليه:** ينطق نص السؤال الحالي كاملاً وينقل تركيز لوحة المفاتيح فوراً إلى نص السؤال ليقرأه NVDA مجدداً. |
| **Ctrl + 2** | **نطق الإجابة النموذجية:** يقرأ الإجابة النموذجية مباشرة في أذن المحكم فقط دون أن تقفز NVDA إليها ودون أن تظهر للمتسابقين. |
| **Ctrl + 3** أو **مسافة (Space)** | **التحكم في المؤقت (التايمر):** تشغيل المؤقت الصوتي، أو إيقافه مؤقتاً، أو استئنافه. |
| **Ctrl + 4** أو حرف **ا (ألف)** | **طلب الخيارات:** يكشف خيارات الإجابة الأربعة ويوقف التايمر في أول ضغطة، وفي كل ضغطة لاحقة يعيد قراءة الخيارات كاملة للمحكم دون المساس بالتايمر. |
| **Ctrl + 5** | **إجابة صحيحة:** في فقرة السرعة الأولى وكسر التعادل: تسجيل إجابة الفريق الأول. في جولات المسابقة: احتساب إجابة صحيحة ونقطة للفريق النشط. |
| **Ctrl + 6** | **إجابة خاطئة وتحويل السؤال:** في فقرة السرعة الأولى وكسر التعادل: تسجيل إجابة الفريق الثاني. في جولات المسابقة: تسجيل إجابة خاطئة وتحويل السؤال تلقائياً للفريق المنافس (ارتداد). |
| **Ctrl + 7** | **لم يجب أحد:** متاح في فقرة أسئلة السرعة التمهيدية وجولات كسر التعادل لسحب سؤال سرعة بديل فوراً عند عجز الفريقين عن الإجابة. |
| **زر استبدال السؤال** | **سحب سؤال احتياطي:** زر متاح على الشاشة لاستبدال أي سؤال معترض عليه بسؤال بديل فوراً من نفس المجال دون التأثير على طابور الأسئلة المجدولة. |

### إدارة التركيز وقراءة الأسئلة التلقائية (Screen-Reader-First)

1. **التركيز التلقائي على نص السؤال (Automatic Focus):**
   - فور انطلاق كل سؤال جديد، تقوم الواجهة بنقل تركيز المتصفح ومؤشر NVDA تلقائياً إلى عنوان السؤال (`h2#question-text`) مع إرسال إعلان ناطق عبر `aria-live`، مما يتيح لدكتور إبراهيم سماع السؤال فوراً دون أن يضطر للضغط على أي زر للبحث عنه.
2. **عزل الصوت الاحترافي (Stereo Mix Isolation):**
   - تبث صفحة الويب المؤثرات الصوتية وصوت التايمر عبر مسار الصوت الافتراضي (Stereo Mix) ليسمعه المتسابقون والمستمعون بجودة نقية، بينما يظل صوت قارئ الشاشة NVDA معزولاً في سماعة المحكم الخاصة.
3. **حماية الإجابة النموذجية من القفز:**
   - عُرضت الإجابة النموذجية في واجهة المحكم دون وسم `aria-live`، حتى لا يسبق قارئ الشاشة بقراءتها قبل أن يقرأ نص السؤال للمتسابقين، مع إتاحة قراءتها بضغطة زر واحدة عبر `Ctrl + 2`.

### مستجدات الإصدار الثاني (v2.0.0)

1. **تنبيهات صوتية وإعلانات نصية حية عند انتقال الأدوار:**
   - إطلاق إشعار صوتي وإعلان ناطق فوري ينبه د. إبراهيم بمجرد انتهاء أسئلة الفريق الأول وانتقال الدور لبدء أسئلة الفريق الثاني في كل فقرة، لضمان وضوح سير المسابقة على الهواء.
2. **منع التكرار الصارم والفحص الاستباقي للرصيد:**
   - فحص استباقي شامل لملف الأسئلة قبل بدء أي مباراة للتأكد من استيفاء رصيد الأسئلة الأساسية والاحتياطية.
   - خوارزمية ذكية تكتشف النقص في أي مجال بعينه بدقة، وتمنع التكرار بنسبة مخصصة (0% حظر تام، وحتى 100%).
3. **استعادة الحالة الآمنة (State Restoration):**
   - استعادة دقيقة ومحكمة لكافة تفاصيل المباراة (النقاط، الفريق النشط، السؤال الحالي، حالة الارتداد، والخيارات المعروضة) فور إعادة تحميل صفحة الويب أو انقطاع المتصفح المؤقت.
4. **نظام كسر التعادل التناوبي (Tie-Breaker Engine):**
   - إدارة آلية لجولات كسر التعادل بطرح أسئلة فردية بالتناوب الدقيق بين الفريقين حتى حسم الفوز، مع تسجيل كافة الأسئلة المطروحة ضمن سجل الأسئلة المستخدمة.
5. **إدارة البطولات وسجل المباريات:**
   - إنشاء وإدارة بطولات متعددة وجدولة المباريات تحت البطولة النشطة.
   - استعراض تفاصيل المباريات المنتهية، ونتائج كل فقرة، مع إمكانية حذف المباريات التجريبية بأمان مع نافذة تأكيد متوافقة مع قارئات الشاشة.

### هيكل فقرات المسابقة ونموذج الأسئلة

تدعم الإضافة قراءة بنك الأسئلة من ملفات نصية مهيكلة (`.txt`). يتضمن المستودع ملف نموذج الأسئلة المكتمل بجميع المجالات:

- **[نموذج_أسئلة_المسابقة_المكتمل.txt](نموذج_أسئلة_المسابقة_المكتمل.txt)**
- **[نموذج_أسئلة_المسابقة.txt](نموذج_أسئلة_المسابقة.txt)**

#### تفصيل فقرات المسابقة:

1. **الفقرة التمهيدية (أسئلة السرعة لتحديد الفريق البادئ):**
   - أسئلة مباشرة (سؤال وجواب) لتحديد البادئ بالاختيار في الفقرات التالية.
2. **الفقرة الأولى (الأسئلة العامة - اختيار من متعدد):**
   - تتضمن 12 مجالاً معرفياً (ديني لغوي، أدب، جغرافيا، تاريخ، علوم، رياضة، فنون، تكنولوجيا، فلك وفضاء، صحة وطب، اقتصاد وتجارة، ثقافة عامة).
   - يُطرح 24 سؤالاً في المباراة (12 سؤالاً لكل فريق)، ويتطلب كل مجال 3 إلى 4 أسئلة لتأمين الأساسي والاحتياطي.
3. **الفقرة الثانية (اختر مجالك):**
   - يختار كل فريق مجاله المفضل، ويُطرح عليه 6 أسئلة مباشرة متتالية في مجاله.
4. **الفقرة الثالثة (أسئلة السرعة الختامية):**
   - 12 سؤال سرعة مباشراً للمباراة (6 أسئلة لكل فريق)، ويتطلب الملف رصيداً كافياً للاحتياطي وكسر التعادل (16 سؤالاً على الأقل).

### طريقة التثبيت والتشغيل

1. **تثبيت حزمة الإضافة:**
   - حمّل الحزمة المباشرة: [thaqqaf_nafsak-2.0.0.nvda-addon](https://github.com/farid5006/thaqqaf-nafsak/raw/main/dist/thaqqaf_nafsak-2.0.0.nvda-addon).
   - اضغط Enter على ملف الإضافة لتثبيتها في NVDA ثم وافق على إعادة تشغيل قارئ الشاشة.
2. **بدء المباراة:**
   - اضغط `NVDA + N` -> توجه إلى قائمة **أدوات** (Tools) -> **ثقف نفسك - مسابقة المعلومات العامة...**.
   - حدد أسماء الفريقين وملف بنك الأسئلة ونسبة التكرار المطلوبة ثم اضغط **بدء المباراة**.
3. **بناء الحزمة من المصدر:**
   ```bash
   python build_addon.py
   ```
